# Officially Supported (& Recommended) Server-side mods

| Name                                 | Purpose                                                     |
|--------------------------------------|-------------------------------------------------------------|
| [LuckPerms][luckperms]               | Roles, Permissions, Prefix-Storage                          |
| [StyledChat][styledchat]             | Chat styling and formatting (Prefix display)                |
| [StyledPlayerList][styledplayerlist] | Player list style/format customization (Prefix display)     |
| [ServerAnnounce][serverannounce]     | Recurring, timed chat broadcasts                            |
| [Kits][kits]                         | Permissions-based player kits for Fabric Servers.           |
| [InvView][invview]                   | Allows you to get the inventory and echest of other players |
| [CommandAliases][commandaliases]     | Enables creating custom commands to run other commands.     |

[luckperms]: https://luckperms.net/
[styledchat]: https://github.com/Patbox/StyledChat
[styledplayerlist]: https://github.com/Patbox/StyledPlayerList
[serverannounce]: https://github.com/John-Paul-R/server-announce
[invview]: https://github.com/PotatoPresident/InvView
[kits]: https://github.com/John-Paul-R/kits
[commandaliases]: https://github.com/FlashyReese/CommandAliases
